# Security Policy — Papastro Framework

Keamanan framework dan aplikasi pengguna merupakan prioritas tertinggi kami.

## Versi yang Didukung

| Versi | Didukung Patch Keamanan |
|-------|-------------------------|
| 3.0.x | :white_check_mark: Ya (Versi Aktif) |
| 2.0.x | :white_check_mark: Ya (Via `php papastro upgrade`) |
| 1.2.x | :white_check_mark: Ya (Via `php papastro upgrade`) |
| < 1.2 | :arrow_up: Harap upgrade ke v3.0.0 via `php papastro upgrade` |

---

## Melaporkan Kerentanan Keamanan (Vulnerability)

Jika Anda menemukan celah atau kerentanan keamanan pada Papastro Framework, **mohon jangan membuat laporan publik melalui GitHub Issues**.

Silakan laporkan temuan Anda secara privat langsung kepada maintainer:
- **Email:** [dhafanavy@gmail.com](mailto:dhafanavy@gmail.com)
- **Subjek Email:** `[SECURITY] Temuan Kerentanan Papastro Framework`

Harap sertakan:
1. Deskripsi kerentanan dan potensi dampaknya.
2. Langkah-langkah untuk mereproduksi masalah (*proof of concept*).
3. Usulan perbaikan kode jika ada.

Kami akan merespons dalam waktu 1x24 jam dan merilis patch keamanan secepatnya.
